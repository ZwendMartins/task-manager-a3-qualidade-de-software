# TaskManager — Projeto A3

## Sobre o projeto

Este repositório foi criado no contexto da Unidade Curricular (UC) de Gestão e Qualidade de Software, com o objetivo de colocar em prática os conceitos, métodos e ferramentas estudados ao longo do semestre.

O projeto consiste na avaliação da qualidade de um sistema open source real, disponível publicamente no GitHub. Para isso, o grupo assume o papel de uma equipe de Quality Assurance (QA), responsável por compreender o sistema, planejar e executar atividades de qualidade e analisar evidências técnicas.

O repositório reúne a documentação, os artefatos e as entregas desenvolvidos pela equipe ao longo das etapas da A3.
